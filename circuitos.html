Circuito com sensor de presença

O sensor PIR detecta movimento por variações na radiação infravermelha, princípio utilizado em alarmes e iluminação automática.

No exemplo, o sensor usa o pino 2 e controla o LED no pino 13: ao detectar movimento, o LED acende.

Exemplo em C++

const int pir = 2;
const int led = 13;

void setup() {
  pinMode(pir, INPUT);
  pinMode(led, OUTPUT);
}

void loop() {
  int movimento = digitalRead(pir);
  digitalWrite(led, movimento);
  delay(100);
}

Circuito com sensor ultrassônico

O sensor mede a distância pelo tempo de retorno de um pulso sonoro, permitindo identificar a aproximação de objetos.

No exemplo, Trig usa o pino 9 e Echo, o pino 10. A distância em centímetros aparece no Monitor Serial, configurado para 9600 baud.

Exemplo em C++

const int trig = 9;
const int echo = 10;

void setup() {
  Serial.begin(9600);
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  unsigned long tempo = pulseIn(echo, HIGH, 30000);
  if (tempo > 0) Serial.println(tempo * 0.0343 / 2); // Distância em cm
  delay(500);
}
